version 8.4 offline · no installation · zero cost

1. What this software is

A self-contained, fully offline retrieval tool for clinical coding. It integrates four coding systems and tolerates disordered, fragmentary queries — the way coders actually remember disease and procedure names.

  • One HTML page plus a data folder. Double-click to run. No install, no network, no server, no GPU.
  • Three exact tiers plus one fallback tier: exact substring → two-character fragments → order-free single characters → partial-coverage fallback (v8.4).
  • The fallback tier is used only when no exact hit exists. It ranks candidates by the fraction of query characters found in the entry name, returns at most the 10 closest matches, and marks them clearly as fuzzy candidates for reference only. It never displaces an exact match.
  • Displays the standard lookup pathway (lead term → code), and cross-references the Chinese national clinical version against the medical insurance version, flagging mismatches ("grey codes") automatically.
  • No training, no annotation, no external model: all matching is deterministic string logic over local tables.

3. How to obtain and run it

Download: ICD_Coding_Query_v8.4.zip (about 8 MB, unpacks to about 60 MB)

Unzip anywhere (local disk or USB stick) and open index.html in Chrome or Edge. A convenience launcher 启动工具.bat is included.

During peer review an anonymised copy of the software is provided as supplementary material so that reviewers can test it without contacting the authors. After publication the version above is the one described in the article.

The tool is intended to be used before the DRG/DIP grouper, i.e. at the moment of coding, so that a coder can see the correct code — and any version mismatch — before the record is grouped, rather than discovering the error at post-hoc audit.

4. Version history

8.4 (current)Adds a partial-coverage fallback tier for queries that match no entry exactly, with output truncated to the 10 closest candidates. On the external clinical-name set this raised Top-1 from 56.4% to 62.4% and Top-10 from 66.7% to 79.7%, with zero rank regressions across 11,331 evaluated queries. Chinese and English interfaces updated together.
8.3Within-tier re-ranking: candidates sharing the same score are re-ordered by character-level similarity between the query and the candidate name (0.6 × bigram Dice + 0.4 × unigram Dice). Recall is unchanged.
8.2 / earlierThree-level disorder-tolerant matching; dual-version cross-reference; digitised lead-term pathways; favourites and history.
